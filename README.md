# 一口小作坊

一款轻松、自由搭配的手绘风蛋糕小游戏。没有订单和倒计时，可以做纯胚子，也可以铺满水果和奶油花。

[在线试玩](https://softmutiny.github.io/cake-studio/)

## 可以怎么玩

- 16 种蛋糕胚、21 种夹心；圆形、方形与心形模具，预览与形状一致。
- 8、6、4 寸胚自由叠成多层蛋糕，每层奶油可选平铺、奶盖或波浪。
- 正俯视与斜视切换，画台放大和平移，手绘内容随表面正确投影。
- 完成作品后获得分数和五档星级；贺卡提供三种模板、文案、颜色、布局和贴纸 DIY。
- 夹心逐勺摆放，堆厚会撑开上层蛋糕；顶面与侧面可装饰。
- 五种花嘴、自选奶油颜色、连续手绘裱花与抹刀动画。一份奶油可挤五笔。
- 装饰无限供应，支持移动、旋转、缩放、图层顺序和撤回。
- 切开查看由实际层次、颜色及夹心落点生成的剖面。
- 收藏、下载成品图与剖面；进度保存在当前浏览器。
- 原创程序作曲《烤箱旁的小圆舞曲》，搭配程序合成的操作音效。

右上角 ♫ 可分别调节背景音乐、操作音效或全部静音。浏览器需要首次点击后才允许播放，离开页面会暂停。

## 本地运行

需要 Node.js，无需安装 npm 依赖。

```sh
npm start
```

打开终端提示的本地地址。测试：`npm test`。`?test=1` 使用独立的测试存档。

存档保存在 localStorage，不上传服务器；不同设备、浏览器和网址各自保存。清除站点数据会清除进度。最多十二片胚、三十六层材料、二十四只收藏。刷新保留作品，不保留撤回历史。

## 代码和音乐

`core.js` 是独立状态模型，`flavors.js` 是口味数据；`renderer.js`、`cutaway.js` 与 `cards.js` 负责蛋糕、剖面和贺卡 Canvas 绘制，`app.js` 处理交互，`audio.js` 负责 Web Audio 合成、混音、音量与页面生命周期。

音乐旋律、和弦和音色写在 `scripts/compose_bgm.py`，可用 Python + NumPy 重新生成 WAV。网页优先使用小体积 Ogg，必要时回退 WAV。素材请求均为本站资源，不依赖第三方音频库或音乐服务。

```sh
python scripts/compose_bgm.py
ffmpeg -i audio/little-kitchen-waltz.wav -c:a libvorbis -q:a 4 audio/little-kitchen-waltz.ogg
```

代码采用 MIT 许可证。原创程序生成音乐随代码采用同一许可证。字体为站酷快乐体，许可证见 `assets/fonts/OFL.txt`。插画包含 AI 辅助生成素材，供本项目游戏展示；未单独授予插画素材包的独立商用或再分发许可。
